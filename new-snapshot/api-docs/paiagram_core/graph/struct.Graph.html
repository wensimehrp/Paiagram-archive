fn heuristic(&self, from: NodeKey, to: NodeKey) -> Distance

The great-circle distance between two nodes, used as the A* heuristic.

This is admissible whenever interval lengths are at least the straight-line distance between their endpoints, which holds for lengths derived from geometry.
