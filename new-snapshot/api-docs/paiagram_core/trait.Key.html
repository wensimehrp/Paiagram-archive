Expand description

A key that packs a timestamp, a client id, and a per-key-type counter into a u64.

Every key type implements this trait by forwarding Key::to_bits to its underlying u64.

fn set_client_id(client: u8)

Sets the client id used by keys allocated afterwards.

The id must be unique among writers that may merge their worlds. Set it before allocating keys; changing it later is safe but advances the timestamp by one centisecond to avoid reusing counters.

fn next_id(state: &AtomicU64, client: u8) -> NonZeroU64

Allocates the next key from state for client.

state holds the previous key; the compare-and-swap loop makes this safe to call from multiple threads without a separate timestamp atomic.
