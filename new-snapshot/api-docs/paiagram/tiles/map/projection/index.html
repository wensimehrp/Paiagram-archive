A dummy [Projection] for positions that are already projected.

walkers expects a geographic [Position] and projects it into the global pixel space. Paiagram instead stores a [Coord] and projects it into an XyPos with the graph’s [CoordType] before it reaches walkers. Since an XyPos is just a scaled Mercator position, this projection is a single scale from XyPos to pixels.
